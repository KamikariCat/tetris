# NORITris

Небольшой тетрис на TypeScript и Canvas. Тёмный интерфейс, пастельные фигуры, тень приземления, следующая фигура и личный рекорд. Работает на компьютере и телефоне без внешних сервисов и шрифтов.

## Запуск

Нужен Node.js 22 или новее.

```sh
npm ci
npm run dev
```

Откройте http://localhost:3000. Для статической сборки выполните `npm run build`: результат появится в `dist/`. Старое `npm start` также собирает приложение.

## Управление

| Действие | Клавиши |
| --- | --- |
| Двигать фигуру | ← / → |
| Повернуть по часовой стрелке | ↑ / X |
| Повернуть против часовой стрелки | Z |
| Ускорить падение | ↓ |
| Мгновенно сбросить | Пробел |
| Пауза / продолжение | Esc / P |

На телефоне доступны кнопки под полем. Свайп влево или вправо двигает фигуру, касание и свайп вверх поворачивают, свайп вниз сбрасывает. Игра автоматически ставится на паузу при переключении вкладки или потере фокуса.

«Заново» сразу начинает новую партию с нулевым счётом. После проигрыша можно сразу выбрать «Играть ещё». Личный рекорд сохраняется в `localStorage`; если хранилище недоступно, игра продолжает работать.

## Правила

Поле — 10 × 20 клеток. Все семь фигур выдаются перемешанными наборами: каждая появляется один раз в наборе. Повороты проверяют занятые клетки и используют небольшие сдвиги возле стен и дна. Это упрощённые повороты, без полной системы SRS и задержки фиксации: мгновенный сброс сразу закрепляет фигуру.

За 1 / 2 / 3 / 4 линии начисляется 100 / 300 / 500 / 800 очков, умноженных на текущий уровень. Ручное падение даёт 1 очко за клетку, мгновенный сброс — 2. Каждые 10 линий повышают уровень и скорость. Пауза сохраняет поле и прогресс.

## Проверки

```sh
npm run typecheck
npm test
npm run build
npx playwright install chromium
npm run test:browser
```

В Linux при отсутствии системных библиотек используйте `npx playwright install --with-deps chromium`. Для уже установленного Chromium можно указать `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium`.

Проверки логики покрывают границы, повороты, сброс, очистку линий, очки, паузу, проигрыш, перезапуск и последовательности игровых действий. Браузерные проверки запускаются для компьютера и телефона. GitHub Actions выполняет все проверки при push и pull request.

`src/game/Engine.ts` содержит игровую логику без браузерных зависимостей, `Element.ts` — движение и повороты, `Renderer.ts` — Canvas, `Game.ts` — интерфейс и управление.
