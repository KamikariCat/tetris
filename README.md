# NORITris

Небольшой тетрис на TypeScript и Canvas. Тёмный интерфейс, пастельные фигуры, тень приземления, следующая фигура и личный рекорд. Работает на компьютере и телефоне без внешних сервисов и шрифтов.

## Запуск

Нужен Node.js 22 или новее.

```sh
npm ci
npm run dev
```

Откройте http://localhost:3000. Для статической сборки выполните `npm run build`: результат появится в `dist/`. Старое `npm start` также собирает приложение.

Для проверки готовой сборки выполните `npm run build && npm run preview` и откройте http://localhost:3001. Preview обслуживает файлы из `dist/` без пересборки в режиме разработки.

## Установка и офлайн

Откройте игру с интернетом один раз, чтобы браузер сохранил её файлы. После этого игру можно запускать, перезагружать и играть без сети; личный рекорд сохраняется на устройстве.

На Android выберите «Установить приложение» в меню браузера. На iPhone откройте игру в Safari, нажмите «Поделиться» → «На экран “Домой”» и включите «Открывать как веб-приложение», если такая настройка показана. Установленная игра открывается отдельным окном.

При следующем открытии с интернетом браузер проверяет обновления. Новая версия устанавливается целиком и начинает работать после закрытия всех окон игры. Ошибка загрузки обновления оставляет предыдущую офлайн-версию рабочей. Service worker включён в production-сборке; для локальной проверки используйте preview. Публикация требует HTTPS (localhost также поддерживается).

## Управление

| Действие | Клавиши |
| --- | --- |
| Двигать фигуру | ← / → |
| Повернуть по часовой стрелке | ↑ / X |
| Повернуть против часовой стрелки | Z |
| Ускорить падение | ↓ |
| Мгновенно сбросить | Пробел |
| Пауза / продолжение | Esc / P |

На телефоне ведите пальцем по полю влево-вправо: фигура перемещается вслед за движением сразу, пока палец касается экрана. Начальное касание не меняет её позицию; расстояние одной клетки на экране перемещает фигуру на одну клетку. Короткое касание и свайп вверх поворачивают, свайп вниз сбрасывает. Можно также использовать кнопки под полем. Игра автоматически ставится на паузу при переключении вкладки или потере фокуса.

Мобильная игра целиком помещается в доступный экран: поле меняет размер при повороте телефона и изменении высоты браузера, кнопки остаются под рукой. Прокрутка страницы, выделение текста и меню долгого нажатия в игре отключены. Кнопка полного экрана появляется в браузерах с поддержкой Fullscreen API.

«Заново» сразу начинает новую партию с нулевым счётом. После проигрыша можно сразу выбрать «Играть ещё». Личный рекорд сохраняется в `localStorage`; если хранилище недоступно, игра продолжает работать.

## Правила

Поле — 10 × 20 клеток. Все семь фигур выдаются перемешанными наборами: каждая появляется один раз в наборе. Повороты проверяют занятые клетки и используют небольшие сдвиги возле стен и дна. Это упрощённые повороты, без полной системы SRS и задержки фиксации: мгновенный сброс сразу закрепляет фигуру.

За 1 / 2 / 3 / 4 линии начисляется 100 / 300 / 500 / 800 очков, умноженных на текущий уровень. Ручное падение даёт 1 очко за клетку, мгновенный сброс — 2. Каждые 10 линий повышают уровень и скорость. Пауза сохраняет поле и прогресс.

## Проверки

```sh
npm run typecheck
npm test
npm run build
npx playwright install chromium webkit
npm run test:browser
```

В Linux при отсутствии системных библиотек используйте `npx playwright install --with-deps chromium webkit`. Для уже установленного Chromium можно указать `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium`. Мобильные проверки проходят в Chromium и WebKit (движок Safari).

Проверки логики покрывают границы, повороты, сброс, очистку линий, очки, паузу, проигрыш, перезапуск и последовательности игровых действий. Браузерные проверки собирают production-версию и открывают её на компьютере и телефоне, включая проверку загрузки CSS и применения оформления. GitHub Actions выполняет все проверки при push и pull request.

`src/game/Engine.ts` содержит игровую логику без браузерных зависимостей, `Element.ts` — движение и повороты, `Renderer.ts` — Canvas, `Game.ts` — интерфейс и управление.
